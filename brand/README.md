# 브랜드 이미지

`python icon.py` 로 다시 굽습니다. 사이트에 배포되지 않고, 바깥 서비스에
올릴 때 쓰는 파일들입니다.

| 파일 | 어디에 |
|---|---|
| `profile-dark-640.png` | **카카오톡 채널 프로필** (권장 640×640) |
| `profile-dark-1024.png` | 깃허브·노션·링크드인 등 어두운 판이 어울리는 곳 |
| `profile-light-1024.png` | 흰 배경 문서·명함처럼 밝은 판에 얹을 때 |
| `mark-1024.png` | 배경 없는 마크만. 직접 배치할 때 |
| `../site/og.png` | 링크 미리보기(1200×630). 카톡 채널 커버로도 쓸 수 있습니다 |

## 왜 이렇게 생겼나

Fornax 는 화로자리입니다. 크기가 다른 별 셋(등급 순서대로)을 옅은 선으로
이은 것이고, favicon 과 헤더 로고와 같은 그림입니다.

프로필 이미지는 대부분 **원형으로 잘려서** 보입니다. 그래서 `icon.py` 는
별의 반지름까지 넣어 가운데 원 안에 다 들어가도록 배율을 계산합니다 —
모서리로 삐져나가면 잘립니다.

선은 헤더 로고보다 가늡니다. 28px 에서 곱던 굵기가 1024px 에서는 막대가
됩니다. 반대로 채팅 목록의 40px 에서는 선이 거의 사라지는데, 그래도
크기가 다른 점 셋이 남으므로 알아볼 수 있습니다.

밝은 판에는 별밭도 빛 번짐도 넣지 않았습니다. 밝은 하늘에는 별이 안
보이고, 넣으면 먼지와 얼룩처럼 읽힙니다.
