# project-forge

프리랜스 개발 스튜디오 **Fornax** 의 웹사이트와 제품 데모 모음.

빌드 도구도 패키지 매니저도 쓰지 않습니다. 파일을 브라우저로 열면 그대로 동작하고,
저장소를 그대로 올리면 그대로 배포됩니다.

| 페이지 | 파일 | 내용 |
| --- | --- | --- |
| 메인 | `site/index.html` | 스튜디오 소개, 대표 작업물, 예상 견적, 견적 문의 |
| 견본실 | `site/gallery.html` | 작업물을 분야별로 모아 보는 곳 |
| PALLET | `site/pallet.html` | 재고 관리 SaaS 제품 데모 (작업물 예시) |
| MAT | `site/mat.html` | 요가·필라테스 스튜디오 회원 앱 데모 (작업물 예시) |
| STAMP | `site/stamp.html` | 사내 결재·지출 관리 데모 (작업물 예시) |
| TAG | `site/shop.html` | 온라인 스토어 데모 — 고객·판매자 양쪽 (작업물 예시) |
| INDEX | `site/guide.html` | 사내 문서 검색 어시스턴트 데모 (작업물 예시) |
| BRIDGE | `site/bridge.html` | 레거시 무중단 이관 상황판 데모 (작업물 예시) |
| TALLY | `site/board.html` | 지표 대시보드와 수집 파이프라인 데모 (작업물 예시) |
| CLERK | `site/clerk.html` | 반복 업무 에이전트와 사람 승인 단계 데모 (작업물 예시) |
| BEACON | `site/landing.html` | 브랜드·랜딩 사이트 작업대 데모 (작업물 예시) |

편집 도구는 따로입니다. `site/publish.py` 가 편집기를 띄우고 공개까지 맡습니다.
`site/admin.html` 은 저장소에 없습니다 (아래 참고).

---

## 실행

서버가 필요 없습니다. `site/index.html` 을 브라우저로 열면 됩니다.

일부 브라우저는 `file://` 에서 로컬 저장소 접근을 막으므로, 밝기 전환 기억 같은
사소한 기능을 확인하려면 간단한 정적 서버를 띄우는 편이 낫습니다.

```bash
cd site && python -m http.server 8000
```

## 내용 고치기

작업 목록과 연락처는 각 HTML 안의 `<script type="application/json" id="site-data">`
블록에 들어 있습니다. 직접 고쳐도 되지만, 편집기를 쓰면 실수가 줄어듭니다.

```bash
cd site && python publish.py
```

크롬이나 엣지가 열리면서 편집기가 뜹니다.

1. `사이트 파일 연결` → `site/index.html` · `site/gallery.html` · `site/privacy.html` 을 고릅니다.
   한 번만 하면 기억하고, 지금 사이트에 들어 있는 내용을 읽어 옵니다.
2. 등록해 둔 것은 한 줄로 접혀 있습니다. 고칠 것만 눌러 펼치세요.
   `+ 작업 추가` 를 누르면 새 항목만 펼쳐진 채로 열립니다.
   많아지면 위의 검색과 분야 단추로 좁힐 수 있습니다.
3. `사이트에 바로 반영` — 두 파일이 함께 갱신됩니다.
   반영·공개 단추는 화면 아래에 붙어 있어 어디서든 누를 수 있습니다.
4. `공개하기` — 무엇이 올라가는지 보여 준 뒤 커밋하고 push 합니다.
   GitHub Actions 가 끝나면 공개된 사이트에 반영됩니다.

`index.html` 과 `gallery.html` 은 같은 데이터를 봐야 목록이 어긋나지 않으므로
편집기가 항상 함께 씁니다. `privacy.html` 에는 연락처와 사업자 정보만 들어갑니다 —
작업 목록까지 실을 이유가 없습니다.

### publish.py 는 무엇을 하나

브라우저는 보안상 스스로 `git` 을 돌릴 수 없습니다. 그래서 아주 작은 서버를
띄워 두고 편집기가 거기에 부탁하는 구조입니다. 조심한 것들:

- **`127.0.0.1` 에만 귀를 엽니다.** 같은 공유기의 다른 기기도 닿지 못합니다.
- **켤 때마다 임시 열쇠를 만들어 편집기에만 심습니다.** 브라우저에 열려 있는
  다른 사이트가 이 서버를 두드려도 열쇠가 없어 거절됩니다. `Origin` 도 봅니다.
- **받는 것은 커밋 메시지 한 줄뿐입니다.** 아무 명령이나 대신 실행하지 않습니다.
- 창을 닫으면 열쇠가 사라집니다.

`git add -A` 는 작업 중인 다른 파일까지 담으므로, 커밋 전에 올라갈 파일 목록을
보여 주고 한 번 확인받습니다.

`admin.html` 을 파일로 직접 열어도(`file://`) 편집과 반영은 되지만, 열쇠가
없으므로 `공개하기` 는 나타나지 않습니다. 그때는 직접 push 하세요.

```bash
git add -A && git commit -m "견본 등록" && git push
```

### 파이어폭스·사파리에서는

직접 쓰기(File System Access API)를 지원하지 않습니다. 예전 방식을 쓰세요.

1. `파일로 저장` → `site-data.json`
2. `cd site && python apply.py` — 두 파일에 함께 넣고 각 파일 옆에 `.bak` 을 남깁니다
3. `git add -A && git commit -m "견본 등록" && git push`

### 실수로 덮어쓰지 않도록

편집기 안의 기본값은 만들 때 찍어 둔 스냅샷이고, 편집 중이던 내용은 브라우저에
남습니다. 둘 다 사이트보다 낡아 있을 수 있어서, 파일을 연결하거나 편집기가 갱신되면
어느 쪽을 쓸지 물어봅니다. 언제든 `사이트에서 읽어오기` 로 현재 내용을 가져올 수 있습니다.

### admin.html 이 저장소에 없는 이유

정적 페이지에는 진짜 로그인을 붙일 수 없습니다. 비밀번호를 코드에 넣어도
소스 보기로 그대로 드러나므로 보안이 아니라 보안 흉내가 됩니다.

그래서 편집기는 **인증을 두지 않는 대신 배포하지 않는** 쪽을 골랐습니다.
`.gitignore` 로 저장소에서 빼고, 배포 워크플로에서도 공개 파일만 골라 올립니다.

**로컬 파일이 유일한 사본이므로 따로 백업해 두세요.**

## 알아 둘 것

### 폰트를 파일 안에 넣었습니다

한글 본문은 [Pretendard](https://github.com/orioncactus/pretendard) 를 쓰는데,
Google Fonts 에 없어서 **페이지에 쓰인 글자만 골라 서브셋한 뒤 인라인**했습니다.
덕분에 외부 요청 없이 뜨지만, 대신 이런 제약이 있습니다.

> **본문 글자를 바꾸면 폰트를 다시 구워야 합니다.**
> 서브셋에 없는 글자는 시스템 폰트로 폴백돼 한 문장 안에서 서체가 섞입니다.
> 현재 `index.html` 기준 한글 733자만 들어 있습니다. 페이지마다 따로 굽습니다.

편집기(`admin.html`)로 내용을 고쳤을 때도 마찬가지입니다.
새로 적은 글자가 서브셋에 없으면 그 글자만 다른 서체로 뜹니다.

```bash
pip install fonttools brotli
python bake.py                     # site 의 본문 페이지 전부
python bake.py site/index.html     # 바꾼 것만
```

마지막에 **빠진 한글 0자**가 찍히는지 확인하세요. 0이 아니면 그만큼 폴백됩니다.
Pretendard 원본(2MB)은 저장소에 넣지 않고, 없으면 `bake.py` 가 한 번 받아 둡니다.

### 서버가 없습니다

- **견적 문의 폼**은 [`worker/`](./worker) 의 Cloudflare Worker(`api.fornaxworks.com`)로
  보냅니다. 첨부까지 그대로 메일로 들어갑니다. 저장소 배포와는 별개로 돌아가는
  유일한 서버 조각입니다.
- **상담 챗봇**은 이 페이지에 적혀 있는 답만 꺼내 줍니다. 모델도 서버도 쓰지 않습니다 —
  아래 참고.
- **PALLET · MAT · STAMP · TAG · INDEX 데모**는 새로고침하면 처음 값으로 돌아갑니다.
- **MAT 데모**의 푸시·딥링크·오프라인·강제 업데이트는 오른쪽 조종판에서 일으키는 흉내입니다.
  실제 발송 서버도, 스토어도 붙어 있지 않습니다.
- **STAMP 데모**의 역할 전환기는 데모용입니다. 실제 시스템에서는 로그인한 계정이 역할을 정합니다.
- **TAG 데모**의 결제 창은 PG 를 흉내 낸 것입니다. 승인·실패·취소를 눌러 고를 수 있게 해 두었습니다.
- **INDEX 데모**에는 모델도 벡터 DB 도 없습니다. 검색 점수는 미리 넣어 둔 개념 벡터로 계산하고,
  재순위는 정답 표를 보고 흉내 냅니다. 설정을 바꾸면 평가 점수가 실제로 움직입니다.
- **TAG 데모의 로그인**은 흉내입니다. 아이디·카카오·네이버 어느 것을 눌러도 같은 데모 계정으로 들어갑니다.
  로그아웃하면 비회원이 되고, 주문번호와 이름이 모두 맞아야 그 주문 하나만 열립니다.
  상품 사진은 자리 채움용입니다 — 실제로 팔 때는 직접 찍은 사진으로 바꿔야 합니다.

### 상담 챗봇

`index.html` 과 `gallery.html` 안에 같은 코드가 들어 있습니다. 서버도 모델도 없습니다 —
낱말 표를 훑어 가장 가까운 항목 하나를 고르고, 그 답을 페이지에서 그대로 꺼내 줍니다.

무료 LLM 을 붙이는 쪽도 재 봤지만 접었습니다. Workers AI 무료 한도는 하루
10,000 뉴런이라 LLM 요청 몇 건이면 바닥납니다. 공개된 페이지에 달아 두면
첫날 오전에 멈추고, 멈춘 챗봇은 없는 것만 못합니다.

고칠 곳은 `KB` 배열 한 군데입니다.

```js
{ id:"price",
  k:[["견적",5],["가격",5],["얼마",4]],   // [낱말, 무게] — 조사는 빼고 어간만
  t:"금액은 범위를 확정한 뒤에 …",          // *별표* 안쪽만 굵게 나온다
  go:[["예상 견적 내보기","#estimate"]],   // 답 아래 붙는 이동 단추
  more:["기간은 얼마나 걸리나요"] }        // 이어서 물어볼 것
```

무게 합이 4 를 넘겨야 답합니다. 못 넘기면 지어내지 않고 문의 폼이나 카카오톡으로
넘깁니다. 길게 적어 주신 문장은 *그 문장 그대로* 문의 양식에 옮겨 담습니다.

### 브랜드 이미지

바깥 서비스(카카오톡 채널·깃허브 등)에 올릴 프로필 이미지는
[`brand/`](./brand) 에 있습니다. `python icon.py` 로 다시 굽습니다.
사이트에는 배포되지 않습니다.

### 카카오톡 상담 채널

`contact.kakao` 에 채널 주소를 넣으면 연락처에 칸이 하나 생기고, 챗봇이 답을 못
찾았을 때 카톡으로 넘기는 단추가 함께 뜹니다. 비워 두면 둘 다 나타나지 않습니다.
`admin.html` 의 **카카오톡 채널 주소** 칸에서 고칠 수 있습니다.

주소는 `https://pf.kakao.com/_코드/chat` 형태로 넣습니다 — `/chat` 을 붙이면
채널 홈이 아니라 채팅창이 바로 열립니다.

채널 설정은 **공개 ON · 검색 허용 OFF** 를 권합니다. 공개가 꺼져 있으면 채널
추가 자체가 막혀 이 단추가 무용지물이 되고, 검색 허용을 꺼도 URL 로는 그대로
열립니다. 즉 사이트에서 들어온 사람만 닿고, 카톡에서 이름으로 찾는 사람에게는
안 걸립니다.

프로필 이미지는 [`brand/profile-dark-640.png`](./brand) 를 쓰면 됩니다.

## 만들면서 정한 것

- **담금질 산화색**을 구조로 씁니다. 쇠가 달아오르며 지나는 색(회청 → 청 → 자 → 주 → 금)이
  진행 단계, 작업 강도, 배경 입자의 온도를 나타냅니다.
- **배경은 입자 물리**로 돌아갑니다. 커서가 지나가면 밀려났다 스프링으로 제자리에 돌아오고,
  밀려난 거리가 곧 열이 됩니다. 60fps 상한과 적응형 품질(프레임이 밀리면 알갱이를 솎음)이
  들어 있어 느린 기기에서도 끊기지 않습니다.
- **작업 카드 프리뷰**는 이미지가 아니라 제품 UI 를 그대로 그린 뒤 CSS 로 축소한 것입니다.
  데모를 고치면 프리뷰도 같이 고쳐집니다. 데모가 있는 작업은 **화면을 세 장씩** 넣어 두고,
  커서를 올리면 넘어갑니다. 모션을 꺼 둔 사람에게는 자동으로 넘기지 않고, 점을 눌러 고르게 했습니다.
- **배경 움직임은 끌 수 있습니다.** 내비의 밝기 버튼 옆 토글로 입자와 마퀴를 멈춥니다.
  계속 흔들리는 화면에 멀미를 느끼는 사람이 있어서 넣었고, 선택은 기억됩니다.
  운영체제에서 이미 모션 최소화를 켜 둔 사람에게는 처음부터 꺼진 상태로 뜹니다.
